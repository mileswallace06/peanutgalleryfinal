## Validation and reproduction

From a clean checkout, the nonmutating local gate is:

```sh
npm ci --ignore-scripts
npm run lint:audit
npm run test:audit-safe
npm run build
npx playwright install chromium
npm run test:audit-browser
```

`test:audit-safe` is an explicit allowlist of **33** offline suites with a network-denial preload; it does not glob the repository's live/canary scripts.
